# Источники и открытые вопросы

## Использованные вложения

| Источник | Что содержит | Куда перенесено |
| --- | --- | --- |
| `Pasted markdown.md` | Информационный пакет HACKALEM AI, 10 разделов кейса | `requirements.md`, без сокращения содержания |
| `ИИ-ассистент для чата на сайте ekt.kz ДАННЫЕ.docx` | Basic Auth, список товаров, пагинация, карточка товара | `ekt-api.md`; реквизиты удалены |
| `Снимок экрана 2026-09-23 в 13.26.03.png` | Трек 10 «Торговля», название кейса, владелец «Электрокомплект», краткое описание | Контекст ниже |

Скриншот подтверждает тему кейса: консультация по характеристикам, наличию и аналогам; добавление в корзину только после явного подтверждения. На нём видны две ссылки «Google Документ» и ссылки на материалы участников, но адреса ссылок на изображении не раскрыты. Дополнительных технических спецификаций из этих ссылок не получено. Конкретный дедлайн на скриншоте не указан.

Исходный Word-документ не включён в пакет, поскольку содержит секреты. Скриншот не добавлен: его содержательный контекст перенесён в текст. Ответы ассистента из предыдущего чата не использовались как источник обязательных требований.

## Что уточнить до реализации соответствующей функции

- Фактические поля ответов EKT API, пагинацию, ошибки и ограничения доступа.
- Источник актуальных правил оплаты, доставки и минимальной партии: значения этих правил во вложениях не указаны.
- Платформу сайта, способ интеграции чата, API корзины и адрес корзины/оформления заказа.
- Единицы количества, правила остатков по складам и возможные ограничения минимальной партии.
- Правила подбора аналогов для конкретных категорий каталога.
- Допустимые размеры и точные расширения вложений, правила хранения пользовательских данных.
- Точную дату полного набора данных: в кейсе она оставлена для отдельного уточнения.
- Контракт между frontend и backend вашей команды.

ТЗ разрешает для разработки и демонстрации анонимизированные или синтетические данные каталога с сохранением структуры полей; для прототипа достаточно репрезентативной выборки. Подключение именно к живому каталогу не следует превращать в дополнительное обязательное требование.
