# EKT — матрица приёмки

Приоритет P0: ложные факты, утечка, несанкционированная корзина; P1: основные сценарии.
AUTO означает выполненный тест реального FastAPI endpoint с временной SQLite и MockTransport,
а не проверку живого EKT. Все перечисленные автоматические тесты активны.
MANUAL означает сценарий без автоматизации. Один метод unittest может содержать несколько subTest.

Они не доказывают качество ответов живой модели.

## B. Реальный /api/chat — 18 активных тестов

Runner: tests/test_chat_acceptance.py, fixtures: qa/chat_cases.py, инфраструктура:
qa/chat_harness.py. LLM означает заданные tool calls mock-провайдера и настоящий
backend, а не проверку понимания текста живой моделью. ID есть в имени метода.

правильный естественно-языковой ответ про сертификат или условия покупки.

## C. Demo/session cart — восемь активных сценариев, все PASS

Все выполняются до LLM; неожиданный вызов модели вызывает ошибку теста.
Используется точный формат контракта «Добавь 2 штуки товара 200300285_».

| ID | Диалог/условие | Критерий |
| --- | --- | --- |
| C01 | Добавь 2 | Пустая корзина, pending_confirmation с ID/артикулом/2 |
| C02 | Добавь 2 → Да, добавь | Повторный detail, demo-cart quantity=2, pending=null, нет checkout |
| C03 | Добавь 2 → Нет | Без изменений, pending=null |
| C04 | Добавь 4 при остатке 3 | Запрет, без молчаливого уменьшения |
| C05 | Да, добавь без предложения | Без изменений и detail |
| C06 | Injection вместо точного подтверждения | Отмена pending, позднее подтверждение также ничего не меняет |
| C07 | После предложения остаток 3→1 | Подтверждение 2 запрещено |
| C08 | Повторное подтверждение | В корзине по-прежнему 2, лишнего detail нет |

Это не настоящая корзина ekt.kz; требование рабочей checkout-ссылки остаётся отдельным.

## Что остаётся вне автоматической приёмки

- Живая LLM: самостоятельный выбор intent, уточнение неоднозначности, семантическая
  достоверность ответа, устойчивость к новым prompt injections. Mock не доказывает это.
- Реальный EKT: актуальные quantity/properties, обезличенные raw fixtures, схема и единицы.
- Источники сертификатов и условий оплаты/доставки/минимальной партии.
- Настоящая корзина/checkout, резервирование, склад/цена/единица в подтверждении.
- Вложения Excel/Word/PDF/JPEG, OCR и инъекции внутри файлов.
- Приватность во всех логах/traces, desktop/mobile поток, живые latency p50/p95.
- Качество аналогов должно быть проверено специалистом по товарной категории.

Прежние отложенные E02/E04/E15 частично автоматизированы F05/F07/F04; остальные
не объявляются покрытыми автоматически. Всего нет skip/expectedFailure, но четыре
активных падения и перечисленные ограничения не позволяют объявить весь кейс принятым.
