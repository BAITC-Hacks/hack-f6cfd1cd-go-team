# EKT — матрица приёмки

Приоритет P0: ложные факты, утечка, несанкционированная корзина; P1: основные сценарии.
AUTO означает выполненный тест реального FastAPI endpoint с временной SQLite и MockTransport,
а не проверку живого EKT. DEFERRED означает запускаемый тест со skip до интеграции.
MANUAL означает сценарий без автоматизации. Один метод unittest может содержать несколько subTest.

Существующие 24 теста дополнительно покрывают Basic Auth, конфигурацию, CORS, транзакционную
синхронизацию, откат при ошибках/отмене, повторы, пагинацию, дедупликацию и изоляцию поиска от сети.
Они не доказывают correctness будущих AI-ответов.

## B. Будущий /api/chat — DEFERRED

Исполняемые входы и ожидаемые outcomes: `qa/chat_cases.py`; runner: `tests/test_chat_acceptance.py`.
Для B01–B18 корзина всегда неизменна, unsupported_claims и sensitive_leaks пусты.

| B03 | Сколько стоит 200300285_? | price=100 из detail, не snapshot price |
| B04 | Какие характеристики? | properties.current=160 A из detail |

Gate приёмки: P0 нарушения = 0; все пять must-have должны пройти функционально.
Skip и expectedFailure не засчитываются в покрытие реализованной функции. Без источников
сертификатов/условий, проверенного аналога и настоящей корзины весь кейс ещё не принят.
